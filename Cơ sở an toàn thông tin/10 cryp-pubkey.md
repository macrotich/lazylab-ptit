# 🛡️ Lab: Tìm hiểu chứng chỉ khóa công khai (cryp-pubkey)

## Các bước thực hiện & Chuỗi lệnh (Solution):

Trên trình duyệt ô **`Search or enter address`** nhập :
```
https://www.yahoo.com
```

```
https://www.facebook.com
```
